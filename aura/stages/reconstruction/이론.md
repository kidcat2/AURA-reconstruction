## 3DGS 기본 알고리즘

1. 전처리 -  초기 가우시안 생성
- 수학적 가우시안의 구성 = M(평균) , C(공분산)
- 3DGS의 초기 가우시안 구성 = M(위치), S(scale), Q(쿼터니언), A(alpha), C(Color = f_dc, f_rest)
    - 공분산은 S, Q로 계산해서 사용
    - Colmap과 매칭
        - M = colmap xyz  
        - S = 최근접 3개의 점에 대한 거리 평균
        - Q = 단위 쿼터니언 (1, 0, 0, 0)
        - A = 0.5
        - C 
            - f_dc = colmap rgb - 0.5 / 0.28209 (0.5는 중간값 맞춤, 0.28209는 기저 함수의 값)
            - f_rest = 0

## 1. Tile Rasterization

1. CullGaussian : 카메라에 안 보이는 가우시안 제거
    - near, far plane 기준 외부 가우시안 제거
    - FOV
2. ScreenspaceGaussian : 3D Gaussian을 2D 화면으로 투영
3. CreateTiles : 화면을 16x16 픽셀 타일로 분할
4. DuplicateWithKey : 각 가우시안에 대해, 가우시안이 속하는 타일 개수만큼 복제, 봑제본에 tile_id + depth 키 부여 
5. SortByKey : 정렬
6. IdentifyTileRanges : 만든 id_key 배열에 대해 타일 별로 구분점을 찾아두기
7. GetTileRange : 타일 하나의 시작 ~ 끝 범위 찾기
8. BlendInOrder : 타일당 Gaussian을 앞에서 뒤로 alpha blending해서 Pixel 색상 계산

- Tile Rasterization 을 하는 이유 : GPU 최적화

### 1-1. CullGaussian
- near, far plane 기준 더 가깝거나 먼 가우시안 제거
- FOV 기준 양옆 시야각, 상하 시야각 외부의 가우시안 제거



## 2. FOV(Field of View : 시야각)**
- 카메라가 얼마나 넓은 각도로 세상을 볼 수 있는지. 좌우각과 상하각으로 결정됨.
- 시야각이 넓다 = 주변이 많이 보인다 = 왜곡이 크다 = 광각렌즈
- 시야각이 좁다 = 주변이 적게 보인다 = 망원렌즈
- 사람 눈은 단안 120, 양안 200도 정도임

그래픽스에서 FOV
- 사람이 결정함. (게임의 시야각 같은 것은 계산되는 것이 아니라, 게임 제작자가 보여주고 싶은 만큼만 보여줌)
- 결정된 FOV로부터 ---> Projection Matrix 계산

3DGS 에서의 FOV
- camera 내부 파라미터로 계산

## 3. Camera parameter
- fx, fy(focal length) : 초점 거리 
    - 초점 거리가 길다 = 시야각이 좁다
    - 초점 거리가 짧다 = 시야각이 넓다
- cx, cy(Principal Point) : 주점, 센서 좌표의 원점(센서의 원점은 중앙이 아니라 좌상단으로 하는 경우가 많음)
- width,height : 이미지 해상도

* 핀홀 카메라의 투영
- FOV_x = 2 * arctan(W/2f_x), FOV_y = 2 * arctan(H/2f_y)

**Limit : Popping Artifact**
- 카메라 이동 시 가우시안이 뚝 나타나거나 사라지는 현상

원인 1. Guard Band 기반 Gaussian cut-off
- Tile Rasterization에서 임의의 가우시안 A가 타일 X에 겹치는지 판정 방법
    > 타일 주변에 여유 영역(Guard Band)를 두고 해당 영역에 가우시안이 안들어 오면 없음 판정(cut-off)
- 하지만 가우시안 자체는 무한히 퍼지는 분포임. 따라서 어떤 타일이든 아주 조금이라도 가우시안이 존재함.(연속적)
- 따라서 어떤 경계를 기준으로 카메라가 넘어가는 순간 임의의 가우시안 A가 Cut-off 되서 사라짐. => 이것이 "뚝 하고 화면이 바뀌는 불연속" 처럼 보임

원인 2. Depth Blending 문제
- 3DGS를 정렬 시 중심 점 좌표로 정렬함.
- 카메라의 이동에 따라 가우시안의 Depth 관계가 뒤바뀌어 버리는 일이 발생하고 이것이 Alpha Blending에 영향을 끼침.

원인 3. Regularization의 부재
- 가우시안 크기/모양에 제한을 걸지 않음.
- 제한을 걸지 않으면 비정상적으로 큰 가우시안, 이상한 모양의 가우시안이 생성됨. 이러한 가우시안은 원인1-2의 주범
