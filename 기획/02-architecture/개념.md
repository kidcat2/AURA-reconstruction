# 개념 설명

---

### SfM (Structure from Motion)
여러 장의 사진에서 카메라의 움직임(Motion)을 분석해 3D 공간 구조(Structure)를 복원하는 기술.
사진들 사이의 공통 특징점을 찾아 카메라가 어디서 어느 방향으로 찍었는지 역으로 계산한다.

### 포인트 클라우드 (Point Cloud)
3D 공간을 수천~수만 개의 점으로 표현한 데이터.
점 하나는 (x, y, z 좌표) + (RGB 색상)으로 구성된다.
Gaussian 생성의 초기 뼈대로 사용된다.

### 카메라 외부 파라미터 (Extrinsic Parameters)
각 사진을 찍은 카메라의 위치와 방향. "카메라가 공간 어디에 있었고 어느 쪽을 보고 있었는가"를 나타낸다.

### 카메라 내부 파라미터 (Intrinsic Parameters)
카메라 렌즈 자체의 특성. 초점 거리, 이미지 중심점 등. 사진 파일의 EXIF 메타데이터에서 읽거나, 없으면 자동으로 추정한다.

### 3DGS (3D Gaussian Splatting)
포인트 클라우드의 각 점을 "반투명한 타원형 공"(Gaussian)으로 표현하고, 어느 각도에서 봐도 원본 사진과 똑같이 보이도록 반복 학습하는 3D 표현 기술.
학습 결과물을 .splat 파일로 변환하면 웹에서 실시간으로 렌더링할 수 있다.

### 클라우드 GPU 서비스
GPU가 설치된 서버를 필요할 때 빌리고 사용한 만큼만 비용을 내는 서비스. 직접 GPU를 구매하지 않고도 모델을 돌릴 수 있다.
- RunPod / Vast.ai : AI 전용 GPU 렌탈. 저렴하지만 오토스케일링이 약함. 소규모(~200명)에 적합
- AWS / GCP : 오토스케일링·로드밸런서·모니터링 생태계가 갖춰진 대형 클라우드. 중규모 이상(200명~)에 적합

### Presigned URL
S3 같은 저장소에 접근할 수 있는 임시 URL. "이 파일 하나만, 이 시간 안에만" 업로드/다운로드를 허용한다. S3 접근 키를 브라우저에 노출하지 않으면서도 직접 파일을 주고받을 수 있게 해주는 보안 메커니즘.

### Lambda
AWS에서 제공하는 서버리스 함수. 이벤트(S3 업로드 완료 등)가 발생할 때만 실행되고, 실행이 끝나면 자동 종료된다. 상시 서버 없이 "GPU 켜줘" 같은 한 줄짜리 작업을 처리하기에 적합. 비용은 호출당 과금.

### CDN (Content Delivery Network)
전 세계에 분산된 서버 네트워크. 사용자와 가장 가까운 서버에서 파일을 전달하여 다운로드 속도를 높인다. AWS에서는 CloudFront가 CDN 서비스.
