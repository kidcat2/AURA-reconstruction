# 법적·정책적 고려사항

---

## 파이프라인

### 1. 영상 수신 및 입력 준비

- [저작권] S3에 영상이 남아 있는 한 저작권 리스크 → 파이프라인 완료 시점에 원본 영상 자동 삭제 정책 필요
- [개인정보] 영상에 얼굴, 개인 공간 등 민감 정보 포함 가능 → 개인정보 처리방침에 "영상 데이터는 처리 완료 후 즉시 삭제" 명시 필요
- [S3 접근 권한] Presigned URL 유출 시 만료 전까지 접근 가능 → 만료 시간 최소화, HTTPS 강제

### 2. 전처리 및 초기 구조 추출

- [중간 파일] 프레임 이미지도 사용자 데이터. GPU 종료 시 자동 삭제. 비정상 종료로 인스턴스가 남아있는 경우 수동 정리 정책 필요

### 3. Gaussian 생성

- [중간 파일] .ply 등은 GPU 종료 시 자동 삭제
- [.splat 보관] S3에 저장되는 최종 결과물 → 보관 기간 정책 필요 (예: 30일 후 자동 삭제, 사전 고지)

### 4. 결과물 전달

- [개인정보 처리] 영상에 얼굴, 개인 공간 등 민감 정보 포함 가능 → 개인정보 처리방침 필요
- [결과물 접근 권한] 본인만 접근 가능해야 함. 공유 기능 시 범위·권한 설계 필요
- [결과물 보관 기간] S3 무기한 보관 시 비용 + 법적 리스크 → 보관 기간 정책 필요

## 웹

### .splat 뷰어 + 씬 편집

- [사용자 업로드 파일] 3D 모델(VRM 등)은 사용자 소유. 프로토타입에서는 브라우저에서만 처리되므로 서버에 올라가지 않음. 확장 시 클라우드 저장이 필요해지면 보관·삭제 정책 필요
- [공간 라이브러리 저작권] 운영자가 제공하는 공간 데이터의 원본 촬영물에 대한 저작권·초상권 확인 필요
