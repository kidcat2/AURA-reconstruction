## PRD : SplatStage

> 현재 단계 : 프로토타입
> ⚡ 표시 항목은 프로토타입 단계에서 간략하게 작성하고 넘어가는 항목. 본 프로젝트 진입 시 보완.

---

## 1. 제품 개요

**SplatStage** : 현실 공간을 3D로 스캔한 배경 위에 나의 3D 모델을 올려 사진을 찍는 웹 기반 창작 스튜디오

### 포지셔닝

- **Unity·Unreal** : 게임 제작 전반을 위한 도구. 기능이 너무 많고 진입장벽이 높음
- **Luma AI** : 현실 공간을 3DGS로 변환하는 도구. 모델 합성·연출 기능 없음
- **SplatStage** : 3DGS 공간 + 내 3D 모델 + 연출·촬영. 이 목적 하나에만 집중한 도구

---

## 2. 문제 정의

**[핵심 문제]** 내 3D 모델을 현실 배경에 올려 사진 찍고 싶은데, 그걸 하려면 게임 엔진을 배워야 한다.

1. VTuber·3D 크리에이터
   - Unity·Unreal을 써야 하는데 머테리얼, 조명 등 게임 제작 개념을 전부 알아야 함
   - 촬영 영상 변환 → 모델 배치 → 결과물 출력을 여러 도구에서 따로 해야 함
2. 3D 아티스트·인디 게임 개발자
   - 현실 공간을 씬에 빠르게 통합하려 해도 게임 엔진을 켜야 하는 오버헤드가 큼
3. 부동산·관광·문화재 시각화 기업
   - 고품질 3D 시각화에 전문 인력과 소프트웨어가 필요함
   - 결과물을 웹에서 바로 공유할 경량 솔루션이 없음

---

## 3. 타겟 사용자

1. VTuber·버추얼 크리에이터 (1차)
   - 상황 : VRM 아바타를 운영하며 방송·콘텐츠 제작. 현실감 있는 배경 합성 수요 있음
   - 페인포인트 : 게임 엔진은 배우기 너무 어렵고, 기존 합성 도구는 3D 배경을 지원하지 않음
   - 행동 패턴 : 간단하고 빠른 도구 선호. 세팅보다 결과물에 집중하고 싶어 함

2. 3D 아티스트·인디 게임 개발자 (2차)
   - 상황 : 3D 씬 작업 시 현실 공간을 레퍼런스나 배경으로 빠르게 활용하고 싶음
   - 페인포인트 : 게임 엔진 없이 현실 공간을 3D로 가져와 씬에 통합하는 간단한 방법이 없음
   - 행동 패턴 : 프로토타이핑 속도 중시. 결과물을 게임 엔진으로 가져가 이어서 작업함

3. 부동산·관광·문화재 시각화 기업 (3차)
   - 상황 : 공간을 고객에게 시각적으로 보여줘야 하나 전용 소프트웨어 도입 부담이 큼
   - 페인포인트 : 전문 인력 없이 웹에서 바로 공유 가능한 3D 공간 뷰어가 없음
   - 행동 패턴 : 직접 촬영 후 바로 웹에서 공유하는 빠른 워크플로우를 원함

## 4. 사용자 여정

### 공간 선택 분기

```
시작
 ├─ [직접 업로드]  .splat 파일 업로드 → 뷰어 렌더링
 └─ [라이브러리]   운영자 제공 공간 목록 → 선택 → 뷰어 렌더링
                                              (확장1부터 제공)
```

### 메인 흐름 (프로토타입 기준)

```
.splat 업로드
 → 공간 렌더링·시점 조작
 → 3D 모델(VRM·GLB 등) 업로드
 → 씬 내 배치·위치·회전 조작
 → 스크린샷 다운로드
```

### 확장1 추가 분기

```
모델 배치 후
 ├─ [포즈 편집]        본 단위 포즈 조작 → 웹캠 표정 반영
 └─ [결과물 export]    Unity·Unreal 호환 파일 / OBS 삽입 포맷 다운로드
```

## 5. 기능 정의 (단계별)

### [프로토타입]

1. .splat 뷰어 - .splat 파일 업로드 후 웹에서 실시간 렌더링·시점 조작
2. 3D 모델 배치 - VRM·glTF·GLB·OBJ 업로드 후 씬 내 위치·회전 조작
3. 스크린샷 - 현재 화면 이미지 파일로 다운로드

### [확장1]

1. 공간 선택 분기 - 직접 동영상 업로드(.splat 변환) 또는 라이브러리에서 선택
2. 전신 포즈 편집 - VRM 본(Bone) 단위 조작으로 T포즈 탈출
3. 웹캠 표정·모션 캡처 - 실시간으로 VRM 모델에 반영
4. 기본 조명·쉐이더 - 배경과 모델의 이질감을 줄이는 최소한의 렌더링 요소
5. 결과물 export - Unity·Unreal 호환 확장자 및 OBS 삽입 가능 포맷 다운로드

### [확장2]

1. 자체 3DGS 파이프라인 - 오픈소스 의존 없이 자체 변환 모델로 교체
2. 물리 기반 조명 - Point Cloud 변환 기반 레이캐스팅·조명 지원
3. 애니메이션 - 키프레임 기반 모델 동작 생성
4. 자체 쉐이더 - 툰 쉐이더 등 기본 탑재 + 사용자 정의 쉐이더 업로드

## 8. 제약 사항 및 전제

- WebGL·WebGPU 미지원 브라우저는 지원 범위 외
- 프로토타입은 .splat 직접 업로드만 지원 (동영상 → splat 변환은 확장1)
- 프로토타입은 1인 개발 기준, 범위 최소화
- 실시간 방송 연동(Warudo 등)은 확장2 이후 검토
- 기술 스택 확정은 03-design 단계에서 진행

---

## 9. 미결 사항

1. 확장1에서 웹캠 모션캡처를 포즈 편집과 함께 제공할지, 별도 단계로 뺄지
2. 공간 라이브러리를 운영자가 직접 올리는 방식으로만 운영할지, 사용자 제출도 받을지
3. 결과물 export 포맷을 확장1에서 지원할지 확장2로 넘길지
4. 실시간 방송 연동(Warudo 등)을 확장2 범위에 포함할지 확장3으로 뺄지
