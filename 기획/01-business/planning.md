## 프로젝트명 : 3DGS 기반 웹 뷰어 제작

---

## 문제 정의

1. VTuber·3D 크리에이터
   - 자신의 모델을 현실감 있는 배경과 합성하기 위해 Unity, Unreal 같은 게임 엔진을 직접 다뤄야 한다
   - 촬영한 영상을 3D 공간으로 변환하고, 거기에 자신의 모델을 올리고, 결과물을 뽑아내기까지 여러 전문 도구를 넘나들어야 하며 진입장벽이 매우 높다
2. 3D 아티스트, 인디 게임 개발자
   - 3D 씬을 빠르게 프로토타이핑하거나 레퍼런스로 활용할 때 게임 엔진을 켜야 하는 오버헤드가 크다
   - 현실 공간을 3D로 스캔해서 씬에 통합하는 워크플로우가 복잡하다
3. 부동산·관광·문화재 시각화 기업
   - 현실 공간을 고품질로 3D 시각화하려면 전문 소프트웨어와 인력이 필요하다
   - 결과물을 웹에서 바로 공유하거나 고객에게 보여줄 수 있는 경량 솔루션이 없다

---

## 타겟 사용자 및 사용 사례

1. VTuber, 버추얼 크리에이터
   - VRM 모델과 현실 배경을 합성하여 콘텐츠 제작
2. 3D 아티스트, 인디 게임 개발자
   - 웹 기반 3D 씬 편집 및 렌더링
3. 부동산·관광·문화재 시각화 기업
   - 현실 공간의 3DGS 뷰어 솔루션 도입

---

## 제안 해결책

웹 브라우저 하나로 3DGS 기반 공간 렌더링부터 3D 모델 합성·촬영까지 하나의 흐름으로 처리할 수 있는 뷰어를 제공한다.

### [프로토타입] 핵심 기능

1. .splat 파일을 업로드하면 웹 브라우저에서 실시간으로 렌더링하고 시점 조작
2. 사용자의 개인 3D 모델(VRM, glTF, GLB, OBJ 등) 업로드 및 씬 내 배치·조작
3. 모델을 원하는 위치·포즈에 배치한 후 스크린샷을 파일로 다운로드

### [확장1] 크리에이터 특화 기능

목표 : 기본 목적("현실 배경에서 모델을 올려 사진 찍기")을 실제로 쓸 수 있는 수준으로 완성

1. 공간 선택 분기 제공
   - 직접 촬영한 동영상 업로드 → 타 3DGS 오픈소스 모델을 활용해 .splat으로 변환
   - 운영자가 미리 스캔·등록해둔 공간 라이브러리에서 선택
2. VRM 모델의 본(Bone) 단위 포즈 조작
   - 단순 position/rotation → 전신 포즈 편집
3. 웹캠 기반 표정·모션 캡처를 VRM 모델에 실시간 반영
4. Shader, Light 등 기본 렌더링 요소 추가
   - 이질감 없는 합성을 위한 최소한의 조명·쉐이더 지원
5. 결과물 파일 export
   - 씬 설정 및 결과물을 Unity·Unreal 호환 확장자로 다운로드
   - 방송 도구(OBS 등)에 직접 삽입 가능한 포맷 지원
   - 실시간 연동(Warudo 등)은 추후 검토

### [확장2] 판매 가능한 소프트웨어 수준으로 완성

목표 : 상용 소프트웨어로서 독립적으로 설 수 있는 완성도 확보

1. 자체 3DGS 모델 개발 및 파인튜닝 기능 탑재
   - 외부 오픈소스 의존 제거, 자체 변환 파이프라인 확보
2. Gaussian Splat → Point Cloud 변환을 통한 조명·레이캐스팅 지원
3. 애니메이션 기능 추가
   - 키프레임 기반
4. 자체 쉐이더 제작 및 무료 제공
   - 툰 쉐이더 등 스타일별 쉐이더 기본 탑재
   - 사용자 정의 쉐이더 업로드 및 수치 조정

## 차별점

Unity·Unreal 등 기존 게임 엔진 대비 이 프로젝트를 선택하는 이유:

1. 단일 목적 캡슐화
   - 게임 엔진의 머테리얼, 물리, 객체 생성 등 게임 제작 전반의 기능을 걷어내고 "현실 공간 + 3D 모델 합성" 하나에 집중
   - 사용자는 [조명] [쉐이더] 같은 목적 단위 항목만 다루면 되므로 진입장벽이 낮음
2. 설치 불필요
   - 웹 브라우저만으로 즉시 사용 가능
3. 워크플로우 통합
   - 공간 선택 → 모델 배치 → 합성 촬영 → 파일 export까지 단일 도구에서 완결
4. 게임 엔진과의 연계
   - 더 깊은 작업이 필요한 사용자를 위해 Unity·Unreal 호환 확장자로 export 가능
   - 이 도구에서 작업한 결과를 게임 엔진으로 이어서 활용할 수 있음
